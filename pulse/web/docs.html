WHAT IS TYRANT//BOT
01

TYRANT//BOT watches KnowYourMeme for trending meme entries, evaluates them against configurable criteria, and automatically launches them as tokens on pump.fun. The entire cycle — from scrape to on-chain transaction — runs without human input once configured.

A FastAPI web server serves a real-time dashboard and maintains WebSocket connections to all open browser tabs, pushing live events as they happen. A SQLite database stores every launch record and count snapshot for historical charting.

◈ All stages are fully non-blocking async. The FastAPI server, launch loop, and WebSocket broadcaster share a single asyncio event loop — zero threads, zero blocking I/O.
▶
PIPELINE
02

Every scan cycle moves through five stages. Each stage is awaited sequentially per meme entry; multiple entries in a cycle run in series up to MAX_LAUNCHES_PER_CYCLE.

RSS / HTML
KYM SCRAPER
Polls KnowYourMeme per configured category slugs. Extracts title, image URL, description, and source URL. Deduplicates against already-seen entries stored in the DB.
FILTER + RANK
SCORER
Filters entries already recorded in the DB. Ranks remaining candidates by recency, category weight, and image availability. Returns the top N entries capped by MAX_LAUNCHES_PER_CYCLE.
UPLOAD CDN
IMAGE FETCH
Downloads the meme's primary image. Uploads it to IPFS / CDN to generate a stable metadata URI for the pump.fun token. Falls back to a placeholder if the image is unavailable.
SOLANA CHAIN
PUMP.FUN TX
Builds the Solana token-creation transaction via the pump.fun API with the initial buy bundled. Signs with the configured wallet key (or defers to browser wallet in sign-flow mode) and broadcasts to the configured RPC endpoint.
SQLITE / WS
DB + DASHBOARD
Inserts the launch record into SQLite with status, mint address, tx signature, and SOL spent. Snapshots the running launch count for the PNL chart. Broadcasts exec, log, and stats events over WebSocket to all connected browsers.
◉
RUN MODES
03
DRY RUN
Full pipeline executes — scraping, scoring, image fetch — but no Solana transaction is broadcast. All records are written with status DRY_RUN. Safe for validating configuration and feed quality.
LIVE
Real transactions broadcast to Solana mainnet via pump.fun. Requires a funded wallet and a valid SOLANA_PRIVATE_KEY in .env. Each launch burns SOL for the initial buy + priority fee.

PNL CHART
05

The main chart plots launches per DB snapshot over time — a bar chart of deltas, not cumulative totals. Each bar represents the number of new launches that occurred between two consecutive count snapshots.

ELEMENTMEANING
SpikeMultiple launches happened in that snapshot window — active cycle.
Zero barNo new launches between snapshots — idle scan cycle.
X-axis labelsHH:MM timestamp of when each snapshot was recorded to SQLite.
Y-axisLaunches per snapshot window. Min pinned to 0.
⚠ The chart plots deltas, not running totals. A flat line at height 1 means exactly one launch per cycle — consistent activity, not a stall.

LOG LEVELS
08
SYSTEM
Bot lifecycle events emitted at startup and on config changes.
TYRANT//BOT initializing... · Mode: DRY RUN · Scan interval: 300s
SCAN
One emitted at the start of each scrape cycle, one at the end. The end message contains "next scan in N s" which resets the scan clock in the dashboard.
Scan #7 — scraping KnowYourMeme... · Cycle #7 complete — next scan in 300s
INFO
General progress messages. Includes meme-detected and about-to-launch notices.
→ Launching: Skibidi Toilet (SKIB)… · No new memes found this cycle
OK
Successful on-chain confirmation. Includes mint address (first 8 chars) and tx signature (first 16 chars).
✓ Launched Skibidi Toilet (SKIB) mint=3xFaK8p2 tx=5CvNmP1qXzAb7w3e
ERROR
Non-fatal error captured in the launch loop. Bot logs and moves to the next entry. Investigate if persistent.
✗ Launch failed: RPC timeout · Loop error: ConnectionRefusedError

LAUNCH STATUS CODES
09
STATUSBADGEDESCRIPTION
LAUNCHED LAUNCHED Token successfully created on Solana mainnet. Both tx_sig and mint_address fields are populated in the DB record.
DRY_RUN DRY_RUN Simulated launch. The full pipeline executed but no real transaction was broadcast to the Solana network. tx_sig contains a placeholder value.

CONFIGURATION
10

All settings are loaded from .env at startup. The Settings panel in the dashboard can update them live — changes are written back to .env and take effect on the next scan cycle without restarting.

KEYTYPEDEFAULTDESCRIPTION
DRY_RUN bool true Disables real transactions. Start here until wallet is funded and settings verified.
SCAN_INTERVAL_SECONDS int 300 Seconds between KYM scrape cycles. Minimum recommended: 120s to avoid rate-limiting.
MAX_LAUNCHES_PER_CYCLE int 3 Max tokens to launch per cycle. Prevents blasting many tokens in a single scan.
PUMPFUN_INITIAL_BUY_SOL float 0.001 SOL amount for the creator initial buy bundled with the token creation transaction.
PUMPFUN_PRIORITY_FEE float 0.0001 Solana priority fee in SOL. Increase during congestion to improve transaction landing probability.
SOLANA_RPC_URL str mainnet-beta Solana RPC endpoint URL. Use a private/dedicated node in production to avoid public rate limits.
SOLANA_PRIVATE_KEY str — Base58-encoded wallet private key. Never exposed via any API endpoint — GET /api/config returns a boolean presence flag only.
KYM_CATEGORIES list ["memes"] KnowYourMeme category slugs to scrape each cycle. Multiple categories broaden the discovery surface.
KYM_MAX_ENTRIES_PER_CATEGORY int 10 Max entries fetched per category per cycle. Controls scrape depth and avoids processing stale content.

SAFETY
14
🔑KEY SECURITY
Store SOLANA_PRIVATE_KEY only in .env. Never commit .env to version control. The API intentionally never returns the key value — only a boolean presence flag.
🧪DRY RUN FIRST
Always validate the full pipeline with DRY_RUN=true before going live. Confirm memes are discovered, scored, and logged correctly. Verify the scan interval and cycle counts look right.
⚡RATE LIMITS
Keep SCAN_INTERVAL_SECONDS ≥ 120 to avoid hammering KnowYourMeme. Use a dedicated Solana RPC node in production to avoid public endpoint rate limits affecting transaction reliability.
🌐NETWORK EXPOSURE
The dashboard runs on 0.0.0.0:8000 by default — accessible on your local network. Never forward this port publicly. Use a reverse proxy with authentication if remote access is needed.
