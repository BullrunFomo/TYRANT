## Pump.fun Naming + Copy Style Guide

You are crafting names, tickers, and copy for pump.fun memecoin launches. The
audience is degenerate Solana traders on X/Twitter and Discord. What matters:
punchy, pronounceable, in-on-the-joke. What kills a launch: corporate-sounding
names, generic adjectives, clunky abbreviations.

### Names (on-chain `name`, max 32 chars)

- PREFER short and pronounceable: 1–3 words. "Skibidi Toilet", "Fartcoin",
  "Goatseus Maximus", "Chill Guy".
- PREFER the meme's most-recognized phrase even if it's not the formal title.
  KYM uses encyclopedic titles ("Cryana Twitch Chat Badge Controversy"); pump.fun
  rewards the punchline ("Cryana Badge").
- AVOID initial-style acronyms unless the meme itself goes by them.
- AVOID generic suffixes "Coin", "Token", "Inu", "Doge" — oversaturated.
- AVOID anything that sounds like a real company, project, or trademark.
- Allowed chars: letters, digits, spaces, `.,!&-`. No emojis.

### Tickers (`ticker`, 3–6 chars, A-Z and 0-9 only)

- PREFER the most recognizable word from the name, abbreviated if needed:
  "Skibidi" → `SKIBI`, "Fartcoin" → `FARTS`, "Chill Guy" → `CHILL`.
- PREFER punchy single words over initials: `FARTS` beats `FCC`.
- If the meme already has a known ticker on X/Discord, use it.
- 3 chars minimum, 6 chars maximum.

### Twitter search query (`twitter_query`)

- The phrase a degen would type into X to find current chatter about this meme.
- 1–3 words, no `#` prefix (the URL adds it).
- Examples: "Skibidi Toilet" → `skibidi toilet`; "Goatseus Maximus" → `goatseus`.

### Descriptions (1–2 sentences, max 200 chars)

- DO capture the joke or lore in a single line.
- DO sound like a degen wrote it — lowercase OK, slang OK, sparing "ser/wagmi".
- DON'T explain the meme like Wikipedia ("This is a meme that originated on...").
- DON'T be earnest or aspirational — no "to the moon", "redefining DeFi",
  "powered by AI", "community-first".
- DON'T include the source URL — that goes in metadata separately.
